User Guide & Instructions

Getting Started

Welcome to DDoS Monitor! This platform provides real-time visualization of global DDoS attacks. Follow these steps to get started:

1. Launch the Globe

Navigate to the 3D Globe page to see real-time attack visualization. The globe shows active DDoS attacks with animated arcs.

2. View Analytics

Check the Analytics dashboard for detailed statistics, attack patterns, and geographical heatmaps.

3. Explore Data

Use the Threat Intelligence page to search and analyze historical attack data and malicious IPs.

Important Note

All data shown is in real-time. Attacks are visualized as they happen, with a 1-2 second delay from actual occurrence.

Understanding Attacks

Each attack on the globe is represented with specific visual elements:

Source Dot (🦠)

Color: Red/Pink - indicates attacker location

Size: Based on attack magnitude

Pulse: Indicates active attack

Target Dot (🎯)

Color: Cyan/Blue - indicates victim location

Size: Based on impact severity

Glow: Shows attack intensity

Attack Arc

Color: Based on attack type and confidence

Curve: Shows attack path over Earth

Particle: Animated along the arc

Color Coding

Color Confidence Level Attack Type Typical Bandwidth
🟣 Bright Pink > 90% (Critical) Massive DDoS, Amplification 2+ Gbps
🔴 Orange-Red 70-90% (High) SYN Flood, HTTP Flood 1-2 Gbps
🟡 Amber 50-70% (Medium) UDP Flood, Application Layer 500M-1Gbps
🟢 Cyan-Green < 50% (Low) Port Scan, Small-scale < 500Mbps

API Integration

Developers can integrate DDoS attack data into their own applications using our REST API.

// Example: Fetch recent attacks
const response = await fetch('https://api.ddosmonitor.com/v1/attacks/recent');
const data = await response.json();

// Example: WebSocket connection for real-time data
const ws = new WebSocket('wss://api.ddosmonitor.com/ws');
ws.onmessage = function(event) {
    const attack = JSON.parse(event.data);
    console.log('New attack:', attack);
};

Available Endpoints:

  • GET /v1/attacks/recent - Recent attacks (last 24 hours)
  • GET /v1/attacks/stats - Statistics and metrics
  • GET /v1/threats/search?ip=... - Threat intelligence lookup
  • GET /v1/geo/heatmap - Geographical heatmap data
  • WS /ws - Real-time WebSocket feed

Frequently Asked Questions

Q: Is the data real or simulated?

A: We use a combination of real attack data from verified sources and synthetic data based on real attack patterns. Real attacks are marked with higher confidence scores.

Q: How often is the data updated?

A: Attack data is updated in real-time via WebSocket. The globe refreshes every second with new attack information.

Q: How accurate is the geographical data?

A: IP geolocation accuracy is typically within city-level for most countries. Some locations may be approximate due to VPNs or proxies.

Q: Can I report false positives?

A: Yes, you can report any inaccuracies via the Report Issue link in the footer. We review all reports within 24 hours.
